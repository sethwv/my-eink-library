# Roadmap

This is a direction of travel, not a release schedule. Priorities can change as real e-reader testing and self-hosted deployments uncover more useful work.

## Now

### Non-Docker, multi-platform release

Produce supported standalone releases for multiple platforms so operators can run the library without Docker.

### Documentation

Document installation, deployment, browser constraints, and contribution with reproducible screenshots.

## Next

### Password reset

Make account recovery clear and reliable with a configured public URL and email provider.

### Account modal cleanup

Clarify account actions and ensure restricted sessions only show controls they can use.

## Future

### Kindle and MOBI support

Explore Kindle delivery and MOBI indexing alongside EPUB without creating a second-class format path.

For the principles behind these priorities, read the [project vision](vision.md). For constraints that affect implementation, read [Known limitations](limitations.md).
