# Roadmap

Long term, larger milestones for the project. These will change and are not certain.

### Non-Docker, multi-platform release *(In Progress)*

Produce supported standalone releases for multiple platforms so operators can run the library without Docker.

> 09/30/26 Binaries are cross-compiled during release, but are majorly untested. Need testers & testing done to make sure these are up to snuff with the docker release.

### Kindle and MOBI support

Explore Kindle delivery and MOBI indexing alongside EPUB without creating a second-class format path.
