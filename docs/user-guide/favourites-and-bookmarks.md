# Favourites

Favourites is the built-in personal shelf. It is useful for keeping a short reading list without changing the EPUB folders on the server.

## Minimum: save a favourite

1. Open a book from the Library.
2. In the **Shelves** section, select **Favourites**.
3. Open **Shelves** in the top navigation, then select **Favourites** to see saved books.

Select Favourites again in the book details to remove the book. Removing it while viewing Favourites also removes the card from that page immediately.

## Advanced: bookmark an e-reader session

If the account menu offers **Bookmark link**, it can create one passwordless link for an e-reader browser that does not retain cookies between sessions.

1. Open the account menu and select **Bookmark link**.
2. Select **Create bookmark link**.
3. When the library opens, use the e-reader browser's own bookmark command immediately.

Treat this link as a password. Anyone who has it can use the library as your account. The link is shown only in the browser address bar after it is created. Creating or regenerating a link invalidates the old one straight away.

## Bookmark-link limits

A bookmark session can browse the library and use shelves, but it is restricted. It does not expose the bookmark-link control or administrator pages. Select **Log in** from the account menu to enter your password and step up to a full session when you need account or administration actions.

{: .warning }
Do not send a bookmark link in email, chat, or a shared note. Regenerate it if an e-reader is lost or the link may have been disclosed.

The application currently provides Favourites as its user-facing shelf workflow. It does not provide controls to create, rename, delete, or directly browse arbitrary shelves.
